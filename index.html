Warum eigentlich?

Kurze Wissensvideos auf YouTube und TikTok: Alltagsrätsel in unter einer Minute erklärt.

YouTube: youtube.com/@warumeigentlich.wissen

Warum eigentlich Upload

„Warum eigentlich Upload“ ist ein privates Werkzeug des Kanalbetreibers. Es veröffentlicht die selbst produzierten Videos des Kanals erst nach manueller Freigabe:

  • YouTube: Upload über die YouTube Data API auf den eigenen Kanal und Abruf der Kanalstatistik.
  • TikTok: Upload über die TikTok Content Posting API als Entwurf in die Inbox des eigenen Kontos. Veröffentlicht wird danach von Hand in der TikTok-App.

Das Werkzeug wird nicht von anderen Personen genutzt.
